# Homebrew tap

Casks for Soham109's open source Mac apps.

```sh
brew install --cask soham109/tap/glasspad
```

The apps are not notarized, so the first time (and after each update) macOS asks you to allow them: System Settings > Privacy & Security > Open Anyway.

Casks are generated from each release's checksums. Source: [Glasspad](https://github.com/Soham109/glasspad).
